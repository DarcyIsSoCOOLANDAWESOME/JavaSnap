# JavaSnap :black_joker:

Welcome to snap. This game is playable in the terminal. You need to clone this repository.

## Rules :question:
Press Enter to play the game "snap".

If the numbers on two cards are consecutively the same eg 3♥, 3♦ - then it is a snap!

Player one goes first and then player 2 goes.
